# ⚡ Antigravity Quota Bar

> **Ультимативный мультиаккаунтный монитор квот Google Antigravity для macOS Menu Bar (SwiftBar), терминала и веб-дашборда.**  
> Разработан на чистом Python 3 standard library без единой внешней зависимости (`pip`).

---

## 📌 О проекте

**Antigravity Quota Bar** решает главную проблему разработчиков, использующих несколько аккаунтов Google Antigravity (Google AI Pro, Ultra, индивидуальные подписки):
1. **Мультиаккаунтность:** В официальном интерфейсе Antigravity виден статус только одного, текущего залогиненного аккаунта. Quota Bar опрашивает и контролирует остатки сразу по **всем подключенным аккаунтам** одновременно в фоновом режиме.
2. **Честный недельный лимит (7дн):** Стандартные API отдают только 5-часовой скользящий слот. Quota Bar обращается к внутреннему эндпоинту `retrieveUserQuotaSummary`, извлекая реальный недельный остаток (`7дн`) и точное время сброса кулдауна.
3. **Автоопределение активного профиля:** При переключении аккаунта в приложении Antigravity плагин на лету считывает активную сессию, выводит именно её в статус-бар macOS (`✨ 94% · 4ч 7м`) и поднимает активный аккаунт на первое место в списке.
4. **0% нагрузки на систему:** Скрипт не держит постоянных процессов в памяти, не использует Electron или Node.js. SwiftBar будит скрипт раз в 5 минут на 1.5 секунды, после чего память полностью освобождается.

## 🏗 Архитектура и как это устроено изнутри

```
antigravity-quota-bar/
├── check_quota.py             # Главное ядро: OAuth, Cloud Code API, CLI, Web Dashboard
├── accounts.json              # Хранилище подключенных аккаунтов (refresh_token)
├── README.md                  # Полная документация проекта
└── plugins/
    └── antigravity_bar.5m.py  # Плагин для macOS SwiftBar (интервал 5 минут)
```

### 1. Авторизация и хранение токенов (OAuth 2.0)
- Авторизация запускается командой `python3 check_quota.py --add`.
- Скрипт поднимает временный локальный веб-сервер на порту `51121` (`OAuthCallbackHandler`) и открывает в браузере официальное окно авторизации Google.
- После согласия пользователя скрипт перехватывает код авторизации (`authorization_code`), обменивает его на постоянный `refresh_token` и сохраняет в локальный зашифрованный по правам файл `accounts.json`.
- Вся авторизация проходит через официальный клиент Google Antigravity.

### 2. Запрос квот через внутренний Cloud Code API
При каждом опросе ядро выполняет 3 шага:
1. **Обновление токена доступа (`access_token`):** Запрос к `https://oauth2.googleapis.com/token` через сохраненный `refresh_token`.
2. **Определение проекта (`loadCodeAssist`):**  
   Отправляет `POST https://cloudcode-pa.googleapis.com/v1internal:loadCodeAssist` с метаданными Antigravity IDE (`DARWIN_ARM64`, `GEMINI`). Сервер возвращает идентификатор проекта пользователя (`cloudaicompanionProject`, например `aicode-consumers`).
3. **Получение структуры лимитов (`retrieveUserQuotaSummary`):**  
   Отправляет `POST https://cloudcode-pa.googleapis.com/v1internal:retrieveUserQuotaSummary` с телом `{"project": "<project_id>"}`.  
   Сервер возвращает сгруппированные бакеты:
   - `Five Hour Limit Remaining` -> процент и `resetTime`.
   - `Weekly Limit Remaining` -> процент и `resetTime`.
4. **Фолбэк:** Если summary-эндпоинт недоступен, автоматически опрашивается резервный эндпоинт `fetchAvailableModels`.

### 3. Автоматическое определение активного аккаунта
Функция `get_active_antigravity_account()` читает системный файл состояния приложения Antigravity:
```text
~/Library/Application Support/Antigravity/app_storage.json
```
Из ключа `jetski.onboarding.lastLoginUsername` извлекается email пользователя, под которым прямо сейчас открыта среда разработки. Если пользователь переключает профиль в Antigravity — плагин мгновенно узнаёт об этом, ставит его на первое место и показывает его баланс в верхней панели.

## 🚀 Команды терминала (CLI)

Все команды выполняются через встроенный интерпретатор Python:

### 1. Просмотр сводной таблицы всех аккаунтов
```bash
python3 check_quota.py
```
Выводит в консоль красивую цветную таблицу со шкалами 5-часового и 7-дневного лимитов по всем аккаунтам.

### 2. Подключение нового аккаунта
```bash
python3 check_quota.py --add
```
Открывает браузер, проводит OAuth-авторизацию и сохраняет новый аккаунт в `accounts.json`. Количество аккаунтов не ограничено.

### 3. Список подключенных аккаунтов
```bash
python3 check_quota.py --list
```
Показывает пронумерованный список email-адресов и дату их добавления.

### 4. Экспорт данных в формате JSON
```bash
python3 check_quota.py --json
```
Возвращает чистый JSON со всеми долями остатка, секундами и таймстемпами сброса. Удобно для интеграции в любые другие скрипты, GeekTool, Raycast или Alfred.

### 5. Запуск веб-дашборда Liquid Glass (Zero-Server)
```bash
python3 check_quota.py --dashboard   # Мгновенная генерация dashboard.html и открытие в браузере (0 процессов в памяти)
python3 check_quota.py --server      # Запуск фонового HTTP-сервера (опционально)
```
Генерирует автономный файл `dashboard.html` и открывает его в браузере. Процесс мгновенно завершается — в оперативной памяти остается 0 фоновых демонов:
- **Карточки квот аккаунтов**: живой мониторинг Gemini и Claude, 5ч и 7дн пулы в широкоформатной сетке 3 карточки в ряд с индикацией активного профиля и кулдауна.
- **Device Token Analytics (Аналитика токенов устройства)**: исторический расход токенов на этом Mac (484 сессии), разделение прямых «Запросов пользователя» и вызовов API модели (агентный мультипликатор ~x11.4), интерактивный график Chart.js с двойной шкалой Y, детализация по месяцам/неделям/дням, пресеты (включая `1 мес` с подневным распределением) и сворачиваемый топ-10 ресурсоёмких сессий.

## 🍎 Настройка SwiftBar (macOS Menu Bar)

1. Установите [SwiftBar](https://swiftbar.app/) (бесплатная open-source утилита для строки меню macOS):
   ```bash
   brew install --cask swiftbar
   ```
2. Откройте SwiftBar и укажите папку плагинов:
   ```text
   /path/to/antigravity-telemetry/antigravity-quota-bar/plugins
   ```
   *(Если у вас уже есть общая папка плагинов SwiftBar, можно просто создать симлинк: `ln -s "/path/to/antigravity-telemetry/antigravity-quota-bar/plugins/antigravity_bar.5m.py" ~/path/to/your/plugins/`)*
3. Плагин `antigravity_bar.5m.py` автоматически появится в верхней панели macOS.

### Как изменить интервал автообновления?
SwiftBar определяет интервал опроса по названию файла:
- `antigravity_bar.5m.py` — каждые 5 минут (установлено по умолчанию).
- `antigravity_bar.10m.py` — каждые 10 минут.
- `antigravity_bar.15m.py` — каждые 15 минут.

Чтобы изменить интервал, просто переименуйте файл плагина в папке `plugins/`.

## 🔒 Безопасность и конфиденциальность

- Все токены сохраняются **строго локально** на вашем компьютере в файле `accounts.json`.
- Никакие данные, токены, логины или статистика не отправляются на сторонние серверы — запросы идут **только напрямую** между вашим Mac и официальными серверами Google (`oauth2.googleapis.com` и `cloudcode-pa.googleapis.com`).
- Используется только стандартная библиотека Python (`urllib`, `json`, `http.server`), что гарантирует отсутствие уязвимостей сторонних зависимостей.
